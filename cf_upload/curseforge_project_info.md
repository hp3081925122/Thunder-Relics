# 雷霆遗迹 / Thunder Relics

## CurseForge 项目资料

- 项目类型：Mod
- 游戏版本：Minecraft 1.20.1
- 加载器：Forge
- 项目名称：Thunder Relics
- 简短介绍：Adds the Thunder King boss, animated royal glaive combat, storm rituals, and a full royal armor set for Minecraft 1.20.1 Forge.

## 项目描述

雷霆遗迹为 Minecraft 1.20.1 Forge 添加雷霆君王 Boss、生物骨骼动画、雷霆王戟、雷霆王铠和雷雨战斗场景。

雷霆君王拥有横斩、连斩、重劈、双手下劈、投掷和引雷仪式等攻击动作。引雷区域使用自定义程序化电弧和落雷预警，避免使用大量原版粒子堆叠。击败 Boss 后会掉落完整雷霆王铠和雷霆王戟。
